Aplicación del Método de Gradientes Conjugados Precondicionado en la Planificación Financiera

Desafío académico de Métodos Numéricos · Mención Ingeniería de Sistemas · Modalidad individual. Se resuelve Ax = b para repartir presupuestos entre cuatro departamentos de TI y se compara una solución directa (Cholesky) con GC y GCP (Jacobi) en tres escenarios.

Datos del estudiante (editables, se guardan en este navegador)

Modelo

Costo cuadrático ½xᵀAx − bᵀx de cuatro áreas; su mínimo cumple Ax = b con A simétrica definida positiva.

Métodos

Cholesky (referencia), Gradientes Conjugados (GC) y GC Precondicionado con Jacobi, tolerancia 10⁻⁶.

Producto

Página interactiva: edite A, b, x₀, tolerancia y máximo de iteraciones y todo se recalcula.

2 Caso financiero y variables

Una empresa debe distribuir su presupuesto anual de tecnología entre cuatro departamentos. Cada variable xᵢ es el presupuesto asignado al departamento i, expresado en miles de bolivianos (Bs).

¿Por qué aparece Ax = b?

La empresa elige x minimizando una función de costo cuadrática:

J(x) = ½ xᵀAx − bᵀx

  • aii > 0: costo marginal creciente del departamento i (rendimientos decrecientes).
  • aij (i ≠ j): interdependencia; positivo = competencia por recursos compartidos (personal, centro de datos).
  • bi: demanda o valor estratégico ponderado de financiar el departamento i.

El gradiente ∇J = Ax − b se anula en el óptimo, y como A es simétrica definida positiva, J es estrictamente convexa y el óptimo es único. Por eso se exigen esas dos propiedades.

Procedencia y justificación de los datos

Los datos son sintéticos y didácticos: no provienen de una empresa real. Se calibraron con criterios de proporcionalidad habituales en presupuestos de TI (el desarrollo concentra más gasto en personal; la infraestructura es intensiva en capital y en divisas; el soporte es gasto operativo menor).

Cada escenario lleva su justificación en la sección 5. Puede reemplazar cualquier valor en el editor (sección 4) por datos reales.

Reglas de negocio (Ingeniería de Sistemas)

  • R1. A debe ser simétrica y definida positiva; si no, la ejecución se bloquea.
  • R2. Un presupuesto negativo no tiene sentido; si aparece, se emite un aviso.
  • R3. Se muestra la participación porcentual de cada departamento en el total.
  • R4. Los escenarios comparten variables y estructura; solo cambian coeficientes y b.

3 Formulación del sistema Ax = b

Se muestra el sistema cargado actualmente en el editor. Se actualiza mientras usted edita.

Escenario activo

Forma matricial

Sistema de ecuaciones

Interpretación: cada ecuación expresa el equilibrio de un departamento. El coeficiente aii penaliza su propio gasto y aij mide cómo el gasto del departamento j encarece (si es positivo) al i.

Verificación: A simétrica definida positiva

Algoritmo GCP implementado (según el planteamiento del desafío)
  1. x₀ dado (por defecto 0); r₀ = b − Ax₀.
  2. Construir M = diag(A) (Jacobi). Resolver M z₀ = r₀ y hacer p₀ = z₀.
  3. Para k = 0, 1, 2…: αk = (rkᵀzk) / (pkᵀApk).
  4. xk+1 = xk + αkpk; rk+1 = rk − αkApk.
  5. Parar si ‖rk+1‖₂/‖b‖₂ < tol o si k+1 = Nmáx.
  6. Resolver M zk+1 = rk+1; βk = (rk+1ᵀzk+1) / (rkᵀzk); pk+1 = zk+1 + βkpk.

El GC simple es el mismo algoritmo con M = I. Se controlan las divisiones entre cero (pᵀAp ≤ 0 o rᵀz ≤ 0 detienen la ejecución con un mensaje).
